### 👨‍💻 **About Me**

I'm a **CSE undergrad at NIT Andhra Pradesh** who likes to build at the seam between systems engineering and applied AI — encrypted payment backends, real-time computer-vision pipelines, geospatial safety routers, 3D web canvases. If it has a tricky architectural problem underneath, I'm probably already poking at it.

Day to day, I work in **C, C++, Python and JavaScript** across the full stack — **React + Three.js** on the front, **Node.js / FastAPI + PostgreSQL + Redis** on the back, and **OpenCV / PyTorch** when the problem needs eyes. I run **Arch + Hyprland** because I like my tools sharp and my workflows keyboard-first.

* 🔭 **Currently shipping** — a **Virtual Time Capsule**, a **Dynamic Timetable** system, and a **Hyprland-shell-inspired 3D portfolio** built on React + Three.js.
* 🌱 **Currently learning** — AI model architectures, deeper applied cryptography, and distributed systems internals.
* 💼 **Past lives** — AI/CRM engineering intern @ **Intuitive Data Solutions**, full-stack dev @ **SmartEd Innovations**, web ops @ **Vulcanzy 2k26 (NIT AP)**.
* ♟️ **Off the keyboard** — competitive **chess**, web-series binges, and endless dotfile tweaking.
